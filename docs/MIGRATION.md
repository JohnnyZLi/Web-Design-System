# Migration

This is a public, high-level rollout plan. Repository-specific implementation details and private product logic belong in their own repositories.

## Phase 0 — Foundation

- Review and approve the specimen.
- Approve the atomic tokens.
- Measure current bundle and performance baselines.
- Add token generation and validation to each consuming repository.

## Phase 1 — Portfolio

- Adopt shared tokens while preserving editorial composition.
- Add shared site identity and site switcher.
- Validate hero, work rows, project pages, contact, 320px width, and 200% zoom.

## Phase 2 — Network Diagnostics

- Adopt shared tokens.
- Preserve test-control and analytical patterns.
- Consolidate stable CSS overrides into owning modules.
- Add stable chart encodings and site navigation.
- Separate ordinary page-load budgets from user-initiated test payloads.

## Phase 3 — RolePacket

- Adopt shared palette, typography roles, focus, and canvas.
- Preserve dense workflow patterns.
- Convert wide sidebar behavior to an accessible compact drawer.
- Consolidate temporary style overrides.
- Keep detailed product state and extension behavior in RolePacket.

## Phase 4 — Cross-site validation

- Confirm each site reaches the other two within two interactions.
- Run responsive, keyboard, contrast, reduced-motion, and grayscale review.
- Register or remove every exception.
- Promote the system to implementation contract only after all blockers pass.
