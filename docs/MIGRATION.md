# Migration and conformance status

This is a public, high-level rollout record. Repository-specific implementation details and private product logic belong in their own repositories.

## Phase 0 — Foundation

Completed:

- Atomic tokens and generated CSS are approved and versioned.
- The exact dot canvas, accessibility foundations, global header, site identity, Sites control, and page-content system are packaged.
- Every consumer validates the same immutable v1.4.0 source before merge.
- Package, release, public-safety, raw-color, import, undefined-token, responsive-content, and version-drift validation are active.

Still required before promoting the system from implementation candidate:

- Record current bundle and performance baselines.
- Complete a manual specimen approval record.

## Phase 1 — Portfolio

Completed:

- The homepage uses shared page rails, section hierarchy, ledes, prose roles, content grids, and responsive transformations while preserving its editorial composition.
- Every project case study uses source-level shared markup for the global header, hero, actions, metadata, sections, prose, process steps, panels, metrics, code, and next-project navigation.
- Contact destinations remain available at compact widths.
- Automated HTML, CSS, design-system, and WCAG checks cover every HTML page.

Manual confirmation still required:

- 200% zoom review across the homepage and each case-study page.
- Final reduced-motion and forced-colors visual review in supported browsers.

## Phase 2 — Network Diagnostics

Completed:

- Shared tokens, exact dot canvas, global header, site navigation, and page-content foundations are integrated.
- Idle, running, error, completed-report, saved-history, methodology, privacy, local-probe import, and imported-report states use the same content hierarchy.
- Metrics, panels, findings, recommendations, tables, service states, actions, and empty/error recovery use shared content and semantic roles.
- The legacy visible grid is disabled rather than layered over the dots.
- Test profiles expose name, duration, and maximum transfer cap without label collisions.
- Methodology, Privacy, and Source remain reachable in the compact header transformation.
- Product charts, measurements, semantic data colors, Worker behavior, and native probe remain product-owned.

Manual confirmation still required:

- Grayscale chart review for every result state.
- 200% zoom review of selectors, result tables, charts, and imported probe reports.

## Phase 3 — RolePacket

Completed:

- Shared palette, typography roles, focus, canvas, global header, Sites control, and page-content foundations are integrated.
- Login, loading, dashboard, new-application intake, tracker, profile, memory, application-detail, fit-analysis, resume-review, notes, versions, empty, warning, and confirmation states use the same content roles.
- Dense workflow patterns and the wide sidebar are preserved.
- The compact layout uses a keyboard-operable off-canvas workspace drawer with focus containment, Escape close, focus restoration, inert background navigation, and reduced-motion support.
- Major workflow states use complete semantic text, surface, and border token triplets.
- Temporary tracker spacing was consolidated into the product adapter.

Still required:

- Continue component-by-component consolidation of the remaining resilience stylesheet without mixing it into behavior changes.
- Perform authenticated 200% zoom and forced-colors review across each core workflow.

## Phase 4 — Cross-site validation

Automated requirements:

- Every owned site reaches the other two within two interactions.
- Owned-site links stay in the same tab.
- Every route uses the same global-header and page-content contracts appropriate to its product.
- Consumer assets match the pinned v1.4.0 source.
- Product CI covers typechecking, builds, application tests, accessibility checks, security scanning, and product-specific packaging.

Manual release checklist:

- Compare the three production headers and major content patterns at desktop and compact widths.
- Test keyboard traversal, menu focus, drawers, forms, tables, and dialogs on all three sites.
- Test 320px width and 200% zoom without document-level overflow.
- Review reduced motion, forced colors, contrast, and grayscale meaning.
- Review all project case studies for media framing, prose rhythm, actions, and next-project navigation.
- Register or remove every remaining exception.

The design system remains an **implementation candidate** until the manual release checklist and performance baselines are recorded.
